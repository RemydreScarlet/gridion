# 02: Why Posit for Cellular Automata? — Theoretical Analysis

## 2.1 CA Computation Pattern

セル・オートマトンの1タイムステップにおける各セルの計算は一般に:

```
s_i(t+1) = f( w_1·s_{i+n_1}(t) + w_2·s_{i+n_2}(t) + ... + w_k·s_{i+n_k}(t) )
```

ここで:
- `s_i(t)`: セルiの時刻tの状態 (スカラー値)
- `n_j`: 近傍オフセット
- `w_j`: 近傍重み (通常は定数)
- `f`: 遷移関数 (非線形。閾値・比較・量子化など)

この計算パターンの特徴:
1. **ドット積**: 近傍ベクトルと重みベクトルのドット積を計算 → **quireの適用範囲**
2. **近傍値の局所性**: 参照が近傍セルのみ → **データパスが単純・決定的**
3. **全セル同一演算**: SIMD/SIMTに最適
4. **時間発展**: 各ステップ同一演算を繰り返す → **パイプライン化容易**

## 2.2 PositのCAにおける利点

### 2.2.1 Tapered Precision

Positは1.0付近で最大精度を発揮する:
```
仮数ビット数 ≈ n - 1 - es - regime_bits
```

CAシミュレーションでは状態値が正規化され1.0前後に分布することが多い（例: 連続状態CA、拡散CA、パターン形成CA）。
この領域でPositはIEEE 754より多くの仮数ビットを確保できる。

**例: Posit(32,2) vs binary32**
| 値の範囲 | binary32仮数ビット | Posit(32,2)仮数ビット | Positの優位性 |
|---|---|---|---|
| ~1.0 | 23 | 26 | +3 bits (保持) |
| ~10^-3 | 23 | 24 | +1 bit |
| ~10^3 | 23 | 22 | -1 bit |
| ~10^-10 | 23 | 13 | -10 bits |

CAで値が1.0付近に集中する場合（多くの拡散・結合写像格子系）、PositはFP32より高精度。
値が極端に小さい/大きい場合でも、Positの広いダイナミックレンジがアンダーフロー/オーバーフローを軽減。

### 2.2.2 Quire: 完全精度近傍総和

CAの近傍総和 `Σ(w_i·s_i)` における誤差解析:

**IEEE 754の場合**:
各積 `w_i·s_i` で丸めが発生 → k個の積の総和で最大 `O(k × ulp)` の誤差
kが大きい（大半径CA）ほど誤差が累積。

**Posit + quireの場合**:
- 各積は完全精度 (`2^(2es) × n` bits) でquireに加算
- 総和完了後に一度だけ丸めてPositに戻す
- 丸め誤差は **1回分** のみ

```
誤差比: IEEE 754 = O(k × ulp), Posit+quire = O(1 × ulp)
```

大半径CA (Large Neighborhood CA / LTL) では半径 r に対して k = O(r^2) の近傍数となるため、
この差は極めて重要:

| 半径 r | 近傍数 k | IEEE 754誤差 (相対) | Posit+quire誤差 (相対) |
|---|---|---|---|
| 1 (3×3) | 9 | ~9 ulp | ~1 ulp |
| 3 (7×7) | 49 | ~49 ulp | ~1 ulp |
| 8 (17×17) | 289 | ~289 ulp | ~1 ulp |
| 16 (33×33) | 1089 | ~1089 ulp | ~1 ulp |

### 2.2.3 NaR (Not-a-Real) の統一

IEEE 754では NaN, +Inf, -Inf を個別に扱う必要がある。Positでは NaR に一元化。
CAの遷移関数において「不正な状態」をNaRで表現でき、ハードウェアが単純化される。

### 2.2.4 ダイナミックレンジ

Posit(32,2) のダイナミックレンジは `10^-38 〜 10^36` と binary32 (`10^-38 〜 10^38`) と同等。
しかし、Posit(16,1) は `10^-6 〜 10^6` と binary16 (`10^-5 〜 10^5`) より広く、
16ビット級でも実用的なレンジを確保。これはPE面積削減に寄与する。

## 2.3 IEEE 754 に対する定量比較

### 2.3.1 精度比較 (連続状態CAシミュレーション)

予測: 連続状態CA (例: SmoothLife, Cyclic CA, 結合写像格子) において、
Posit(32,2) は binary32 より約0.5-1.0桁高い実効精度を発揮。

**検証方法**:
- 同一CAモデルを binary64 (Gold Standard), binary32, Posit(32,2) でシミュレーション
- 一定ステップ後の状態の相対誤差を測定
- 誤差の時間発展を評価

### 2.3.2 ハードウェアコスト比較

| 演算器 | IEEE 754 FP32 | Posit(32,2) | 比率 |
|---|---|---|---|
| 加算器 (LUT) | ~300 | ~450 | 1.5x |
| 乗算器 (LUT) | ~400 | ~600 | 1.5x |
| MAC (LUT) | ~800 | ~1200 | 1.5x |
| MAC+quire (LUT) | N/A | ~5000 | N/A |

(Based on PHAc/Big-PERCIVAL synthesis data, Xilinx Virtex-7 / 28nm ASIC)

Posit演算器はFP32比で約1.5倍の面積。ただし、CA固有の特性により:
- quireは複数演算で共有可能 → 1PEあたりのコスト増分は緩和
- Posit(16,1) 採用で面積を大幅削減可能 (16bit級はbinary16比で競争力あり)

## 2.4 想定されるトレードオフ

| 要素 | メリット | デメリット |
|---|---|---|
| Posit(32,2) | FPGA比+0.5〜1桁精度、広DR | 面積1.5倍 |
| Posit(16,1) | 面積小、高速 | 精度制限 (es=1で仮数最大13bit) |
| Quire | 完全精度総和 | 面積増 (big-PERCIVALでコア面積の30%) |
| 専用演算器方式 | 任意遷移関数 | LUT方式よりHW複雑 |
| LUT方式 | 単純高速 | ルール固定・柔軟性低 |

## 2.5 結論

CA専用アクセラレータへのPosit採用は以下の理由から有効:

1. **近傍総和の完全精度計算** (quire) が数学的に正当
2. **1.0付近のtapered precision**が連続状態CAの精度向上に寄与
3. **NaR一元化**でHW単純化
4. **広いダイナミックレンジ**でアンダーフロー軽減
5. **Posit(16,1)とPosit(32,2)の選択肢**により面積vs精度のトレードオフが柔軟

特に、CATが対象とするLarge Neighborhood CAにおいて、qureによる誤差蓄積抑制効果は顕著であり、
Gridionの主要なセールスポイントとなる。
