# 04: PE Array Topology

## 4.1 8×8 Mesh Array

Gridionは8×8 = 64個のPEを2次元メッシュ状に配置:

```
   Col 0    Col 1    Col 2    ...  Col 7
Row 0 [PE0,0]--[PE1,0]--[PE2,0]--...--[PE7,0]
        |        |        |             |
Row 1 [PE0,1]--[PE1,1]--[PE2,1]--...--[PE7,1]
        |        |        |             |
Row 2 [PE0,2]--[PE1,2]--[PE2,2]--...--[PE7,2]
        |        |        |             |
  ...    ...      ...      ...    ...    ...
        |        |        |             |
Row 7 [PE0,7]--[PE1,7]--[PE2,7]--...--[PE7,7]
```

### 4.1.1 近傍結合 (Moore 8近傍)

各PEは8方向の隣接PEから値を受信:

```
(-1,-1) (0,-1) (+1,-1)
(-1, 0) [SELF] (+1, 0)
(-1,+1) (0,+1) (+1,+1)
```

**物理配線**: 各PEから8本の出力 → 隣接PEへ直接配線。
エッジのPEは未使用ピンが発生（境界処理が必要）。

### 4.1.2 境界処理

| 方式 | 説明 | HWコスト |
|---|---|---|
| 固定値 (0埋め) | 境界外を0/NaRに固定 | 最小 |
| 周期境界 (トーラス) | 反対端と接続。配線が長距離に | 大 (ラップアラウンド配線) |
| ミラーリング | 境界で反射 | 中 |
| 外部I/O | FPGA外部メモリから境界値を供給 | 大 (メモリIF必要) |

**推奨: 設定切替可能**。MODEレジスタで境界種別を選択:

```verilog
// 各PEの近傍値選択（エッジ時）
always_comb begin
    if (col == 0 && west_neighbor_needed) begin
        case (boundary_mode)
            FIXED:  west_val = 0;  // or NaR
            PERIODIC: west_val = pe_array[7][row].state;
            MIRROR: west_val = pe_array[0][row].state;  // self
        endcase
    end
end
```

## 4.2 クロックツリーと同期

8×8の小規模アレイでは単一クロックドメインが現実的。

- 全PE同一クロックで同期動作
- グローバル・タイムステップカウンタで世代管理
- 各ステップ終了時に `done` 信号を集約、全PE完了を確認後次ステップへ

## 4.3 グローバル制御ユニット

```
+----------------------------------------------------------+
|  Global Controller                                        |
|                                                            |
|  +------------------+  +------------------+                |
|  |  Sequencer       |  |  Weight ROM      |                |
|  |  (microcode ROM) |  |  (8×9×N bits)    |                |
|  +------------------+  +------------------+                |
|        |                       |                            |
|  +------------------+  +------------------+                |
|  |  Broadcast Bus   |  |  Boundary Config |                |
|  |  (全PEへ同報)    |  |  (エッジ設定)    |                |
|  +------------------+  +------------------+                |
|        |                       |                            |
|  +------------------------------------------------------+  |
|  |  PE Array 8×8 (64 PEs)                               |  |
|  +------------------------------------------------------+  |
+----------------------------------------------------------+
```

### 4.3.1 Broadcast Bus

グローバル制御 → 全PEへの同報信号:

| 信号 | 幅 | 説明 |
|---|---|---|
| `opcode` | 6 | 遷移関数マイクロ命令 |
| `weight_load` | 1 | 重みテーブル更新トリガ |
| `weight_data` | N (16/32) | 重み値 (逐次ロード) |
| `step_sync` | 1 | タイムステップ同期 |
| `boundary_mode` | 2 | 境界モード切替 |
| `reset` | 1 | PE内部状態リセット |

### 4.3.2 データI/O

ホスト（RISC-V or x86）とのデータ転送:

| チャネル | 幅 | 方向 | 用途 |
|---|---|---|---|
| 状態書込み | 64×N | H→D | 初期状態ロード |
| 状態読出し | 64×N | D→H | シミュレーション結果取得 |
| 制御レジスタ | 32 | H→D | MODE/WEIGHT設定 |
| 割込み | 1 | D→H | シミュレーション完了通知 |

**スループット**: 
- 状態ロード: 64 × 4 bytes (Posit32) = 256 bytes / 転送
- PCIe Gen3 x16: ~16 GB/s → 約16M回の初期状態ロード/秒
- 1タイムステップのデータ出力: 256 bytes → 約62M step/秒の結果読出し

## 4.4 ホスト連携

### 4.4.1 RISC-V 統合 (将来的)

小規模なRISC-Vコア (例えば Ibex) をGridionと同一FPGAに統合:
- 制御用HOST CPUとして動作
- メモリマップドI/OでGridionを制御
- PVU/PuPU スタイルのPosit ISA拡張と共存可能

### 4.4.2 PCIe / CAPI (大規模向け)

大規模ホスト連携には PCIe (Alveo) または OpenCAPI ( POWER ) を想定。
- Unum_matrix_multiplier の方式を参考に DMA 転送で状態更新
- ホスト側ドライバでcuPositライクなAPI提供

## 4.5 大規模アレイへの拡張

### 4.5.1 マルチチップ接続

Gridion 8×8をベースチップとして、複数チップを接続:

```
+--------+   +--------+   +--------+
| Gridion|-->| Gridion|-->| Gridion|--> ...
| 8×8    |   | 8×8    |   | 8×8    |
+--------+   +--------+   +--------+
     |            |            |
     v            v            v
+--------+   +--------+   +--------+
| Gridion|-->| Gridion|-->| Gridion|--> ...
| 8×8    |   | 8×8    |   | 8×8    |
+--------+   +--------+   +--------+
```

- チップ間接続: High-speed SERDES or HBM
- エッジPEの入出力をチップ間I/Oに割当
- マルチGPU的なハロー交換プロトコル

### 4.5.2 大規模単一アレイ

FPGAの制約がなければ、より大規模アレイも可能:

| アレイサイズ | PE数 | Posit(16,1) LUT概算 | Posit(32,2) LUT概算 |
|---|---|---|---|
| 8×8 | 64 | ~470K | ~1.4M |
| 12×12 | 144 | ~1.0M | ~3.2M |
| 16×16 | 256 | ~1.8M | ~5.8M |
| 32×32 | 1024 | ~7.2M | ~23M |

## 4.6 物理設計の考慮点

### 4.6.1 FPGA配置

各PEはFPGA上の1つのCLB領域に割り当て:
- Xilinx Alveo: 1 CLB ≈ 8 LUT + 16 FF
- Posit(16,1) PE ≈ 5500 LUT → 約688 CLB
- 8×8 = 64 PE → 約44,000 CLB
- Alveo U280: 約130,000 CLB → 十分な余裕

### 4.6.2 ルーティング

Moore近傍配線:
- 各PEから8本×Posit幅の出力配線
- 8×8アレイで 8 × 16 × 64 = 8,192本 (Posit(16,1))
- 階層配線(H樹)を推奨
- タイミング制約: 全PEの近傍転送を1サイクル内に完了

### 4.6.3 スケーラビリティ

8×8は最新FPGA1枚に収まるバランスサイズ。
プロトタイピングに最適でありながら、マルチチップ拡張により大規模CAも処理可能。
